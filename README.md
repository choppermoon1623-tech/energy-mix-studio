# ⚡ エネルギーミックス・スタジオ

中学生向けの**エネルギーミックス体験シミュレータ**です。
電源構成（発電方法の割合）を自分で決めると、**電気代・CO₂・電気の国産率・停電しにくさ**がその場で計算されます。

👉 **公開URL: https://choppermoon1623-tech.github.io/energy-mix-studio/**

## できること

| 機能 | 内容 |
|---|---|
| ミキシング卓 | 9種類の発電方法をフェーダーで配分（授業の「バンドメンバー」メタファーを継承） |
| 4つのものさし | ①電気代 ②CO₂排出量 ③電気の国産率 ④安定供給（予備率）をメーターで採点 |
| 必要な設備の量 | 太陽光パネルの面積、風車の本数、原発・火力の基数、蓄電池の量を「**登別市◯個分・北海道の◯%**」などで実感 |
| 現実チェック | 「日本ではそれ以上増やせない理由」（適地・国立公園・建設期間など）を自動で指摘 |
| 国際情勢イベント | 中東紛争・豪州の輸出停止・LNG争奪戦・円安・猛暑・原発停止の6シナリオで、電気代と予備率の変化を計算 |
| 発電所図鑑 | 9種類の発電所の姿をイラスト（SVG）で収録。「煙突があれば火力」「まん丸なタンクはLNG」など見分けかたを解説 |
| プリセット | 今の日本(2023年度) / 2030年度目標 / 2040年度目標 / 再エネだけ / 火力だけ / 原子力たより |

## 授業での使いどころ

スライドの流れに対応しています。

- **※考えよう②（変換効率）** → 「6. 発電所図鑑」と「7. メンバーの能力データ」の表
- **3つのものさし** → 「2. 4つのものさしで採点」
- **※④挑戦 あなたのバンドを組もう** → 「1. ミキシング卓」＋「4. 現実チェック」
- **※⑤聞きあって、もう一度考えよう** → プリセットの2030/2040年度目標と比べる、「5. もしも、世界で何かが起きたら」

**ねらい**：全部のものさしを同時に満たす答えは存在しません。「何を我慢して何を取るか」を自分で決める経験をさせるための教材です。

## 主なデータの出典

- 第7次エネルギー基本計画（2025年2月18日 閣議決定）― 2040年度の電源構成目標
- 発電コスト検証ワーキンググループ「発電コスト検証に関するとりまとめ」（2025年2月6日）― 2040年の発電コスト試算
- 電力中央研究所 ― 電源別ライフサイクルCO₂排出量
- 資源エネルギー庁 電力調査統計（2023年度 発電電力量 9,854億kWh）
- 財務省貿易統計（2024年）― 燃料の輸入先
- 日本風力発電協会（2025年末 累積 6,434MW・2,866基）
- 総務省家計調査（2025年）― 4人世帯の電気代 月13,928円
- 面積の比較は 登別市 212.21km²／北海道 83,424km² を使用

計算式の詳細はアプリ内の「📚 データの出典と、計算のしかた」に記載しています。

## 技術

単一の `index.html` のみ。ビルド不要・外部ライブラリなし。グラフ・メーター・発電所のイラストはすべてインラインSVGで描画しているため、拡大しても劣化せずプロジェクタ投影に向きます。
